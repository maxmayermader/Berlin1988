Bring the live PartyKit room server into agreement with `main` before anything is pointed at it.

deployment wired to a room server running pre-Phase-3 code would make Phases 6-10 verify against
a fiction — the exact failure mode v1.0's retrospective names, relocated one layer down. The
evidence is direct: the `directory` party that Phase 3 added 404s on the live host today.

Output: a redeployed Cloudflare worker whose party list matches `apps/party/partykit.json`, and a
two-browser proof that the current client can create and join a game against it.
</objective>
